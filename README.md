# Guizão Lanches

Landing page responsiva criada com React e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

No Windows, dê dois cliques em `ABRIR SITE.bat`. Ele instala as dependências caso faltem e abre a página no navegador. Deixe a janela do terminal aberta enquanto usa o site; feche-a para encerrar o servidor.

## Build de produção

```bash
npm run build
npm run preview
```

Os produtos, valores, avaliações e links estão centralizados em `src/data.js`. As operações da sacola e a composição da mensagem do pedido ficam em `src/cart.js`. Os arquivos da marca e o vídeo controlado pelo scroll ficam em `public/assets`.
